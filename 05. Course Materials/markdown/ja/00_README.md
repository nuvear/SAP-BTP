# コース教材: SAP BTP上のガバナンスされたAI

Raj Academy、SAPエンジニア向けハンズオンコース。このフォルダー内のすべての教材は英語、日本語、簡体字中国語で用意されています。コード、コマンド、ファイル名、引用は3言語で共通です。

## 受講者向け

| ページ | 内容 |
|---|---|
| `03_Student_Workbook.html` | ハンズオンのワークブック: パートAはラップトップ演習（SAPアカウント不要）、パートBは自分のSAP BTPトライアルテナント。タスクにチェックを入れ、回答とメモを入力し、「Save my copy」をクリックすると記入済みのファイルをダウンロードできます。 |
| `04_Lab_Guide.html` | ラボごとに1セクション: 各ペルソナが何を尋ね、何が返り、それが正しいかどうかとその理由。セッション後に読んでください。 |

自分の言語のページを開いてください: `English/`、`Japanese/`、`Chinese/`。すべてのページの上部に言語切り替えがあります。チェックと回答はブラウザごとに保存され、言語を切り替えても引き継がれます。

コードは <https://github.com/nuvear/SAP-BTP> にあります: `apps/`（データサービス、ポリシーローダー、MCPサーバー、デプロイガイド、ラボコンダクター）と `data/northwind/`（11件のポリシー文書と3件の堅牢性文書）。

## 講師向け

各言語フォルダー内の `instructor/` には、セッションランブック（デッキに対応付けた1日分のアジェンダ）、デモスクリプト（ライブデモを質問ごとに記述）、解答例が入っています。これらのフォルダーは `.gitignore` によって公開リポジトリから除外されています。デッキは `../04. Governed_AI_on_SAP_BTP.pptx` です。セッション中に使うステージページ（一度に1ステップずつ、ラボの図と記録済みの証跡付き）は、非公開のClaudeアーティファクトです。

## ファイルの作り方

`markdown/en`、`markdown/ja`、`markdown/zh` にソースがあります。英語のソースはライブのClaude Docs（ランブック、デモスクリプト、ワークブック、ラボガイド）のスナップショットで、翻訳はそのスナップショットから作成されています。`tools/build_package.py` が `tools/build_handbook.py` を使ってソースからすべてのHTMLページをビルドします。ライブ文書を編集した後は、再度エクスポートしてリビルドしてください。
